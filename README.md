# esp-idf-test

This repository is my current ESP-IDF learning workspace. I have already set up the ESP-IDF environment, installed the ESP-IDF VS Code extension, and am now working through the example projects included in the official ESP-IDF repository to learn the framework hands-on.

## Current setup

The environment is ready for ESP32 development, including:

- ESP-IDF installed and configured locally
- ESP-IDF VS Code extension enabled
- access to the ESP-IDF repository examples for experimentation

## Goal

The goal of this repository is to document the learning process while exploring ESP-IDF examples, experimenting with real firmware, and building a stronger understanding of how ESP32 projects are developed in practice.
